## train

- **1:13.2** Trusted code tuned a ridge on three rolling yearly folds. The strongest penalty, ten thousand, gave the lowest error.
- **1:21.1** Then it trained a compact temporal network. Validation loss was best at epoch five, so training stopped at epoch eight.
- **1:28.8** The saved network was reloaded, and reproduced all forty-three thousand predictions exactly.

## evidence

- **1:35.2** An independent evaluator scored every model on the same rows. The neural network did not beat the ridge.
- **1:41.7** And in high pollution hours, every learned model lost to simply repeating the last value.
- **1:47.3** So the lead recommended keeping the existing lagged ridge. These years were used before, so this is not an independent test.

## gate

- **1:55.2** No model approves its own work. The decision waits for a person, with a signed key.

## data

## no

- **2:10.4** Sometimes, the right answer is no. Reject a reused model. Abstain on a fire source. Ask a person for better imagery.

## proof
