## Limits

- Each case tests one input against one check. A pass does not show resistance to other inputs.
- `bearing_mean` and `rain_rate` compare a claimed number with production geometry. No production guard reads such a claim; the met code averages u and v and keeps totals apart.
- `approval` uses a test key in a temporary store. Forged and mismatched cases write the approval file directly, as an attacker with file access would.
- No case calls a model. The suite tests the deterministic gates, not model behaviour.
